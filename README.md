# stripsql

Strip identifiers and sql tokens for idempotent workflows.

**Site:** https://theworker02.github.io/stripsql/

## Install / run

```bash
git clone https://github.com/theworker02/stripsql.git
cd stripsql
node src/cli.js
node --test
```
