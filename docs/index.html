Overview

Strip identifiers and sql tokens for idempotent workflows. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/stripsql.git
cd stripsql
node src/cli.js --help
node --test
